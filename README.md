# Ферма "Наследие предков" - Спецификация игры

## 1. Обзор проекта

**Название:** Ферма "Наследие предков"  
**Тип:** Браузерная RPG-симулятор фермы  
**Жанр:** Сельскохозяйственный симулятор с сюжетом  
**Целевая аудитория:** Казуальные игроки, любители фермерских игр

## 2. Сюжет и сюжетные линии

### Основной сюжет
Главный герой получает письмо от умершего дедушки, который оставил ему старую заброшенную ферму в деревне. Герой приезжает на ферму и должен восстановить её, выполняя волю дедушки.

### Сюжетные эпизоды
1. **Эпизод 1: Прибытие** - Знакомство с фермой, получение задания
2. **Эпизод 2: Первый урожай** - Посадка и выращивание первых культур
3. **Эпизод 3: Новые соседи** - Знакомство с жителями деревни
4. **Эпизод 4: Животноводство** - Приобретение животных
5. **Эпизод 5: Наследие** - Завершение восстановления фермы

## 3. Геймплей

### Фермерские механики
- **Грядки:** 6 грядок для посадки культур (морковь, помидоры, кукуруза, пшеница)
- **Животные:** Коровы, куры, овцы (требуют постройки загонов)
- **Inventory:** Система хранения урожая и предметов
- **Деньги:** Заработок от продажи урожая

### Ресурсы
- Деньги (золотые монеты)
- Семена (морковь, помидоры, кукуруза, пшеница)
- Урожай
- Продукты (молоко, яйца, шерсть)

## 4. Интерфейс

### Экраны игры
1. **Главное меню** - Начало игры, продолжить
2. **Катсцены** - Сцена с повествованием
3. **Диалоги** - Разговоры с NPC
4. **Ферма** - Основной игровой экран
5. **Инвентарь** - Просмотр и управление предметами
6. **Магазин** - Покупка семян и животных

### Визуальный стиль
- Пиксель-арт эстетика
- Тёплые, пастельные цвета
- Плавные анимации
- Сезонные изменения (весна/лето/осень/зима)

## 5. Персонажи

### Главный герой
- Имя: Игрок (можно выбрать)
- Внешний вид: Фермер в рабочей одежде

### NPC
1. **Дедушка (призрак/воспоминания)** - Даёт наставления
2. **Мария** - Торговка в магазине
3. **Пётр** - Фермер-сосед
4. **Анна** - Хозяйка мельницы

## 6. Технические требования

- Один HTML-файл со встроенным CSS и JavaScript
- Адаптивный дизайн для разных экранов
- Сохранение прогресса в localStorage
- Звуковые эффекты (опционально)
